# WWWD Website Design Translation Brief

Status: active prototype brief
Date: 2026-05-13

## Source Intent

WWWD is not a conventional architecture portfolio. It is a spatial intelligence platform operating across architecture, interiors, objects, AI fabrication, construction intelligence, cultural research, and spatial strategy.

Target feel: Apple + Linear + Flora, translated rather than copied.

- Apple: cinematic clarity, confidence, restraint, luminous atmosphere.
- Linear: operational precision, modular cards, dark/light discipline, structured navigation.
- Flora: living research canvas, connected ideas, creative field behavior.
- RISD lesson: simple organization, words with weight, playful/beautiful image rhythm, non-dingy atmosphere.

## Doctrine Application

From `openclaw-state/universal-design-doctrine.md`:

1. First impression is strategy: first screen must say “spatial intelligence platform,” not “architecture office.”
2. Cognitive fluency before feature density: each section has one job.
3. Typography is the first UI system: large sans-led hierarchy, restrained body text, clear labels.
4. Narrative focal point: the Living Index is the organizing interface idea.
5. Visual rhythm: luminous fields, modular glass cards, index tiles, status tags, spatial gradients.
6. Strategy before surface: audience is collaborators, clients, institutions, cultural/tech partners, and future WWWD collaborators.
7. Responsive starts with parent/child structure: hero, capability grid, living index, process rail, work cards, studio/contact each define mobile behavior.
8. AI/taste control: avoid generic startup gradients, generic stock architecture, real-estate imagery, and decorative complexity.

## Homepage Section Jobs

1. Hero
   - Job: establish category and emotional authority in 5 seconds.
   - Message: “WWWD builds spatial intelligence across architecture, objects, systems, and cultural environments.”
   - Action: Enter the Index / View Work.

2. What WWWD Does
   - Job: clarify scope without listing services like an office brochure.
   - System: five capabilities as precise modules.

3. Living Index Preview
   - Job: make the platform feel alive and research-driven.
   - System: card field of projects, references, notes, objects, essays, and systems.

4. Process System
   - Job: show operational intelligence.
   - Flow: Observe → Interpret → Structure → Prototype → Build.

5. Selected Work
   - Job: show output evidence without becoming a portfolio grid.

6. Studio Statement
   - Job: give voice, authorship, and invitation.

7. Contact / Collaborate
   - Job: clear next step.

## Visual Rules

- Base mode: luminous off-white / warm graphite with dark-mode-ready tokens.
- Use subtle spatial texture and depth, not heavy gradients everywhere.
- Cards: rounded but disciplined, soft borders, low shadow, glass-like depth.
- Typography: refined sans-led system; large confident statements; body text compact and calm.
- Motion: subtle entrance, hover lift, small parallax/magnetic feel only where useful.
- Imagery: no generic stock architecture as the main identity. Use abstract spatial placeholders, gradients, material textures, diagrams, and future owned images.

## Prototype Requirements

- Responsive single-page React prototype.
- Tailwind CSS.
- Framer Motion for subtle animation.
- Placeholder arrays for index cards, projects, capabilities, process steps.
- Clean component structure.
- Polished enough for early launch presentation.

## Anti-Copy Boundaries

- Do not clone Apple, Linear, Flora, or RISD layouts.
- Translate logic: clarity, precision, living canvas, word-weight.
- Avoid startup cliché language and generic portfolio imagery.
