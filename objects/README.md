# WWWD Objects

WWWD Objects is a material research and fabrication sub-platform of WWWD.

It explores how travel fragments, 3D scanning, AI-assisted form-making, digital reconstruction, mold-making, wax, light, and ritual can become collectible domestic objects.

## Current prototype

- `visual-brand-kit.html` — static visual brand kit for WWWD Objects / Wax Archive.

Open the file directly in a browser, or link to it from the main WWWD website prototype.

## Strategic position

This is not a conventional candle brand. The candle is the first product format because it sits at the intersection of object, atmosphere, ritual, impermanence, and material transformation.

The larger project is an R&D platform for:

- Scanned artifacts
- AI-assisted form studies
- Fabrication testing
- Wax casting
- Ritual objects
- Domestic atmosphere
- Future object systems beyond candles
